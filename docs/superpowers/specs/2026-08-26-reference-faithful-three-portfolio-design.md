# 参考图高保真 Three.js 作品集重建设计

日期：2026-08-26

## 目标

重做现有作品集的视觉模型与转场，使其严格遵循用户提供的四张参考图。体验保持三屏结构：

1. 黄色文件夹封面。
2. 五个分类文件夹目录，点击后弹出书册式或票据式详情。
3. `THANK YOU` 致谢页与下方两张错位白纸。

第一阶段使用参考图中的文字、颜色和构图；个人信息及真实项目内容放在第二阶段替换。

## “1:1”验收定义

“1:1”指参考图可见正视角中的以下元素按逐项对照方式重建：

- 主体外轮廓、长宽比例和屏幕占比。
- 前后遮挡关系、纸张露出量、标签位置与倾斜角度。
- 蓝、黄、白及五个目录文件夹的主题颜色。
- 大标题、手写装饰字、中文主标题、小字信息区和底部装饰条的位置与层级。
- 文件夹圆角、袋口高度、后袋层、纸张边缘和顶部拼贴物。
- 书册页缝、书脊、索引标签、金属夹、贴纸群和纸张厚度。
- 票据锯齿边、折角、后层便签、下方纸条、黄色图标标签和文字区。
- 致谢页的超大标题、两张错位白纸、联系方式文字和黄色底条。

参考图没有提供背面、底面或真实尺寸，隐藏表面采用一致的纸张、涂层卡纸、塑料和金属材质合理补全。项目不声称不可见区域的制造级精确复刻。

## 技术方案

### Three.js 模型

所有主体由代码生成的 Three.js 几何组成，不把整张参考图贴到单一平面：

- 文件夹与票据使用自定义 `Shape` 轮廓、`ExtrudeGeometry`、薄壳和独立倒角。
- 纸片、文件夹前袋、后袋、标签和底条分别建模，拥有独立深度和稳定部件名称。
- 书册使用左右页组、中心书脊、页边、索引标签、金属夹和贴纸层。
- 目录顶部拼贴采用程序化剪影、简单图标和分层卡片，不复用参考图中的人物、品牌标识或水印素材。
- 文字、线条与平面图形通过高分辨率 `CanvasTexture` 放到独立纸片材质上；几何厚度、折角、锯齿、页缝和连接件不能由纹理冒充。

### 字体策略

参考图中的具体商业字体不可从低分辨率图片可靠识别。首版使用本地可用字体组合模拟：超窄无衬线大标题、斜体手写装饰字、圆角几何无衬线和等宽票据字。排版尺寸、字距、行距与位置优先匹配；若用户后续提供字体文件，再替换为精确字形。

### GSAP 动画

引入官方 `gsap` 包，通过显式时间线控制 Three.js 对象属性。GSAP 不创建模型，只编排模型的位移、旋转、缩放、透明度与镜头：

- 封面进入目录：标题分层退出 → 文件夹前片绕底部铰链翻开 → 白纸上浮 → 镜头推进 → 目录文件夹交错弹入。
- 文件夹详情：未选对象缩小、降亮并后退 → 选中对象移动到中心 → 前袋下翻 → 详情模型从袋内上升并展开。
- 书册：封面及左右页沿书脊展开；换页时当前纸张旋转、下一项目纹理在遮挡阶段替换。
- 票据：后层卡片依次弹出；换项目时主票据横向滑出，下一张从反方向补位。
- 关闭详情：严格反向收拢，再恢复目录排布。
- 进入致谢：目录整体向下沉入 → `THANK YOU` 字母交错进入 → 两张白纸从底部错位升起。
- 重新浏览：致谢纸张回落、标题退出、封面重新组装。

所有时间线在开始时设置过渡锁；结束或中断时统一清理。`prefers-reduced-motion` 下把复杂位移替换为短淡入淡出，并保留全部导航功能。

## 页面与模型设计

### 第一屏：封面

- 画面比例以参考图上半部分为基准。
- 蓝色背景铺满视口。
- 顶部超大黄色 `PORTFOLIO` 接近屏幕两侧边缘。
- `2024` 与白色手写 `Graphic Design` 交叠在大标题上。
- 黄色文件夹位于下半部，背板带中部标签，白色纸张从袋内露出。
- 前袋为向右倾斜的梯形轮廓，显示“老板您好”及倒影式装饰文字。
- 左右信息区和底部黄色细条分别建模为独立文字载体。

### 第二屏：五分类目录

- 采用参考图的亮蓝背景和低矮圆角文件夹比例。
- 桌面按 3+2 排布，手机按 2+2+1 排布。
- 每个文件夹包含后袋、前袋、上方拼贴剪影和下方白色分类标题。
- 五个主题色取自参考图的蓝、绿、橙、黄和粉色。
- 分类继续使用品牌视觉、UI/网页、海报编辑、插画、动态/3D，后续可只改内容数据。

### 书册式详情

- 参考红色背景、白色打开书册、中心页缝和左右金属夹。
- 保留左右内容页、右侧索引标签和贴纸群的视觉密度。
- 首版贴纸使用原创文字与图形组合，保持参考图的尺寸、方向和重叠节奏。

### 票据式详情

- 参考紫色背景和白色主票据比例。
- 主票据具有右上折角、下方锯齿边、后层黄色便签、序号卡和下方窄纸条。
- 使用等宽字体、黑色线条、红色局部强调和黄色图标块。

### 第三屏：致谢

- 以参考图下半部分为基准。
- 顶部超大黄色 `THANK YOU`，白色年份与手写装饰字交叠。
- 下方两张白纸一前一后，后纸略向左倾斜，前纸基本竖直。
- 前纸显示“感谢观看 / Thank you / Thanks for watching”。
- 左下角显示 `PLEASE contact me`，底部保留黄色装饰条。

## 代码结构

- `src/models/cover.ts`：高保真封面模型。
- `src/models/directoryFolder.ts`：目录文件夹及程序化拼贴工厂。
- `src/models/book.ts`：书册详情。
- `src/models/ticket.ts`：票据详情。
- `src/models/thanks.ts`：致谢模型。
- `src/animation/timelines.ts`：GSAP 时间线与取消、减弱动画策略。
- `src/experience/PortfolioExperience.ts`：状态机、点击检测、模型生命周期与时间线协调。
- `src/content/portfolio.ts`：可替换内容数据。

模型工厂继续返回 `SculptModelHandle`，但动作方法由 Promise 化时间线驱动。场景控制器不直接修改模型内部部件。

## 测试与验收

- 单元测试覆盖状态转换、目录布局、GSAP 时间线锁、动作取消、项目纹理切换和资源释放。
- 浏览器流程覆盖封面进入目录、五个文件夹、两种详情、关闭、致谢和重新浏览。
- 桌面 1440×900 与手机 390×844 分别截图。
- 为封面、目录文件夹、书册、票据和致谢模型增加正面及左右斜视 QA 截图，确认几何厚度和连接关系。
- 每张参考图制作同尺寸对照图，人工逐项核对可见轮廓、比例、颜色、层级和关键细节。
- 自动像素指标只作辅助；参考图包含压缩、字体未知和拼贴内容差异时，不以单一分数冒充视觉验收。

## 非目标

- 不在第一阶段替换个人信息或真实作品。
- 不使用后台、账户、音效、物理模拟或外部 GLB 模型。
- 不承诺参考图未展示区域的精确形状。
- 不直接复制参考图人物、商标和水印；用原创程序化拼贴保持相同视觉密度和层级。
