# YY-CV

Three.js 交互式 3D 作品集

一个由 Three.js 程序化几何、CanvasTexture 与 GSAP 时间线构成的交互作品集：参考图式黄色文件夹封面、五分类拼贴文件夹目录、手风琴式 AI技能页、滚动堆叠的项目经历卡片，以及双纸卡致谢页。

## 运行

```bash
npm install
npm run dev
```

生产检查：

```bash
npm test
npm run build
```

## 替换内容

项目内容集中在 `src/content/portfolio.ts`。修改分类标题、简介、标签和主题色不需要改动模型代码。

第二个“校园经历”文件夹的真实内容位于 `src/content/education.ts`。学校资料、荣誉与学术实践在这里维护；手账按正文宽度和可用高度自动换行、生成跨页，页数不再固定。桌面保留 3D 翻页，700px 以下窄屏显示可滚动的阅读页面，共用同一翻页状态。

第四个“AI技能”文件夹是手风琴详情页，内容与图片清单位于 `src/content/skillWorkbench.ts`（骑行营销工作台、数据取数智能体、桌面任务管理助手、商品详情图生成 Skill、骑行营销会场视觉工作流），页面由 `src/skills/skillsWorkbenchPage.ts` 挂载，图片放在 `public/assets/skills/`。宽屏下面板横排，鼠标悬停、点击或键盘聚焦都会把该面板展宽并显示完整图文，面板内容可独立滚动；窄屏下面板改为纵向排列、点按展开。

面板正文只印中文原文（英文翻译保留在数据里但不渲染）。截图按每张图自身的比例排成两列大图，点击任意一张打开预览：画面按 **80vw** 显示，长图在预览里上下滚动而不是缩成窄条（源图太小最多放大到 3 倍）；篇幅大的几张（`public/assets/skills/full/`）会在打开预览时按需加载更高清的版本，先出的缩略图与高清图比例一致，因此换图不会跳动。`←`/`→` 翻页，`Esc`、`×` 或点击空白处关闭。窗口高度不足时，手风琴保持最小高度并让整页上下滚动，而不是把面板和图片压小。

第五个“项目经历”文件夹是一页滚动卡片，内容位于 `src/content/projectExperience.ts`：第一张卡片是 AI 生成的 BooM 蓝莓小人作业，沿媒体框切换主视觉、品牌视觉长图和 2 分 47 秒短片，点击「查看详情」会打开带原生控制的视频弹层；第二张卡片是转转骑行配件前端表达方案，点击「查看完整 PDF」打开 `public/assets/projects/zhuanzhuan/zhuanzhuan-internship.pdf`；第三张卡片是京东超市「洗护焕发青年力」校园营销实习项目，卡片文案与预览图取自 `个护分享：洗护焕发青年力` 这份 10 页分享（预览图 `public/assets/projects/jd/jd-campus-hero.png`），点击「查看完整 PDF」打开 `public/assets/projects/jd/jd-personal-care.pdf`；第四张卡片把河南卫视实习期间写的五篇公众号图文按原文封面排成索引，点「阅读公众号原文」打开对应稿件；第五张卡片是快手实习期间做的一整套技术品牌 AI 视觉，八张成图（马年新春主视觉、AAAI 2026 与 NeurIPS 2025 会议海报，以及星空、发光树、3D 购物车、3D 工具箱、超市机器人五张插画素材）放在 `public/assets/projects/kuaishou/`；第六张卡片是河南卫视实习期间做的视频号短片，「厮跟着到新密」的六条城市短片（青春街头、文明城市公益、银基摩天轮、新密旧味、小城市井人物、元宵节去处）封面也收在 `public/assets/projects/henan-tv/`，卡片外侧给每一条单独排一个「查看详情」按钮，点哪一条就打开那条视频号内容；第七张卡片收录之前参加比赛的作品与获奖记录，九段素材放在 `public/assets/projects/awards/`（七段 GIF 动图 + 两张截图：新闻采访、思政讲课校一等奖、讲文物历史故事、思政课微电影、科学传播、MG 动画科普、防震减灾科普讲解、中广视讯杯鼓励奖、毕业设计展），画面即片段，所以编号切换条排在媒体框顶部、桌面上带作品名，窄屏只留编号并把作品名放到卡片下方的按钮里；GIF 体积大，不参与首屏预加载，跟着卡片一起加载。所有卡片共用同一宽高比，长图切换到该页时自动上下扫视，短片切换到该页时静音循环；纯静图的画廊把编号排在框内、超过五个自动换行，避免压住角标。卡片左右交替，卡片外侧放说明与详情按钮；宽屏是「大卡片 + 侧边说明」，窄屏自动变成「卡片在上、说明在下」。

项目卡里的每张静图都能点开放大：点画面本身，或点侧边说明里为每张图单独列出的按钮（有短标签的画廊才会列出，例如快手的「新春 / AAAI / NeurIPS / 星空 / 发光树 / 购物车 / 工具箱 / 机器人」），都会打开同一层图片查看器 —— 顶部显示「当前 / 总数」，左右按钮或 `←`/`→` 翻页，`Esc`、`×` 或点空白处关闭；关闭后焦点回到刚触发的那颗按钮，卡片也停在刚看过的那张。放大后的画面按窗口铺满：小图最多放大到自身像素的 5 倍（240×135 的 GIF 会铺到约 1200×680），大图只缩不放，窗口变化时重新计算。侧边主按钮「查看大图」对静图同样打开这层查看器；只有 PDF、公众号原文和短片继续走原来的新窗口或播放器。

## 交互

- 点击或触摸 3D 文件夹进入目录和详情。
- AI技能页用横排手风琴呈现：悬停展宽面板，点击可固定，`←`/`→` 在面板之间移动焦点；点击面板内的截图可放大查看原图。
- 文件夹翻开、镜头切换、书册展开、票据弹出与致谢纸张升起由 GSAP 时间线编排。
- 项目经历页跟着滚动堆叠：顶部标题固定不动，交接时上面的卡片上移、缩小到约 84% 并降低透明度退到后面；下面那张则从前面补上来 —— 一开始比正常尺寸大约 12%，随着落位线性收到 100%，所以是「先大后小」地坐进画面，而不是从小长到大。每张卡片会完整停留到滚动进度约 56% 后才开始退场，并用更长的滚动区间完成交接；卡片本体、媒体、文案和编号还会分别跟随鼠标与滚动做视差。长图扫视改为只动画 `transform`，滚动时只更新视口附近的卡片，并移除了影响流畅度的模糊滤镜。
- 项目经历页支持滚轮/触摸滚动，`↑`/`↓`、`PageUp`/`PageDown`、`Home`/`End` 在卡片之间翻页，底部进度条可直接跳到某一项；`Esc` 或「返回作品目录」关闭。
- 详情页支持点击、左右滑动、鼠标滚轮与方向键切换项目。
- `Escape` 返回目录，封面按 `Enter` 可进入目录。
- 键盘 `Tab` 会显示语义控制条；系统开启“减少动态效果”时会缩短转场。

## 建模说明

所有可见主体均为有厚度的 Three.js 几何，文字与平面设计通过高清 CanvasTexture 贴到独立纸片上。参考图只有单视角，因此隐藏侧面使用一致的纸张、塑料与金属材质做风格化补全，不视为制造级精确复刻。
